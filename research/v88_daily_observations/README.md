# V88 交易日发布滞后补采（研究用途）

**起因**：2026-10-20早些时候单日来源返回HTTP 404，但同日北京时间次日凌晨GitHub Actions在原始附件中成功保存了`20261020.csv`。经独立复核，SHA256相符、5568条原始记录日期一致、5217条沪深股票日线，其中3433条原始涨跌幅为正（样本内比例65.8041%）。**这不是中证全指指数收益，也不是正式上市股票池广度。**

## 生产隔离

- [现有V84研究工作流](../../.github/workflows/v84-readiness-research.yml)增加北京时间07:45的次日补查，原19:30查询保留。
- 每次检查当前日起最近9个自然日内的工作日（不假称是中国官方交易日历）。按最新向过去查找第一个发布且内部完整的源数据。
- `probe_recent.json`明确记录请求日、真实数据日、滞后自然日与失败尝试。只将成功取得的日期原始证据摘要写入`ledger/YYYY-MM-DD.json`，不覆盖首次摘要。如后续获取的数据SHA变化则标记CONFLICT。
- 原始大文件仅存GitHub Actions临时附件，保留30天。GitHub中的小型永久日志只有来源URI、哈希、真实观测日、条数和原始上涨占比；没有完整原始CSV时，无法靠该摘要独立复原全部逐股行情。
- 这套观察来自单一非官方源，仅证实源当日数据的格式，不证明历史证券身份、停牌、融资余额、指数价格、换手率和时点可得性。**不得喂入正式Top/Bottom信号或把观察日当作完整模型日**。
