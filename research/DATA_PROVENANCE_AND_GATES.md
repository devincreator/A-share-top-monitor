# 数据来源、含义及质量门禁（2026-10-20）

## 1. 保留两个独立研究轨道

**A）中证全指 000985 官方指数研究轨道**：2015年至2026年10月13日，共2859个有效旧交易日、V52标签客观顶底合计157个，底/顶严格交替。不可将旧版沪深300标签当作同一指数真实历史直接拼接。

**B）2005年以来长期沪深300价格研究轨道**：早年历史来自固定版本数据仓库 [sky910140/financial-agent-takehome@e0710880](https://github.com/sky910140/financial-agent-takehome/tree/e071088057946de60ba1622dec8a69acce1481cd/data/market)，2015年以后沪深300价格以官方冻结记录为准。外部2016-01-04收盘3470.410、官方3469.07冲突1.34，必须保留。成交量单位和跨供应商连续性未完全统一，原V63模型已禁用成交量。

**C）个股广度回溯历史轨道**：2005年242天来自 `https://money-tree.eyunzhu.com/daily_kline/date/YYYYMMDD.csv`，原始CSV与 SHA256已归档GitHub研究预发布。股票基础表 `/stocks/stocks_list.csv` 由**不同日期快照混合**：当前上市20261019、已退市20260524；它不是每年当时可得的历史官方股票池。BaoStock原本计划独立验证，但GitHub Actions网络连接 `bs.login()` 失败。

## 2. 2005年确定事实

- 242/242日，314838条逐股行情；原始每个日期文件均有 SHA256清单。
- 2371条日线不能关联到回溯证券主表；另有213条`600018.SH`同代码历史不同证券主体冲突；合计2584条**应留痕的身份异常**。
- 2005年按历史交易代码累计观察到1367个不同沪深代码；**这不是经过认证的2005年上市公司数**。
- 14665条“回溯候选股票池应出现但当天缺日线”：**不能直接认定为停牌**，也不能填零、当平盘、删掉后称全A股广度。
- 仅针对已经有行情的身份异常做敏感性实验，日均上涨占比变化0.0823个百分点、单日最大0.2897个百分点。对候选无日线的条件性上下界，平均宽4.45个百分点、最大13.97个百分点，非正式置信区间。
- `000638.SZ`具有2005年暂停上市的历史证据；`600018.SH`在2006年发生同代码主体更替。相应引用与出处见 [V78—V82实测报告](reports/V78_V82_实测报告.md)。两者都**不意味着已取得独立全市场历史停复牌每日表**。

## 3. 时间可得性门禁（必须同时满足）

1. 全日期指数交易日历、全代码逐日交易记录与版本锁定哈希齐全；HTTP429导致缺日必须单独补采、独立合并验证。
2. 使用 `security_listing_id` 标识**证券上市片段**，另保留公司ID与交易代码；处理代码更名/跨公司复用/吸收合并，价格不得无条件串接。
3. 每天的股票池必须由在当时成立的上市片段、上市/退市/停复牌公告或等价独立证据重建，不能使用今天的存续名单替代。
4. 上市正常但无日线时需要可审计状态：`CONFIRMED_SUSPENDED`、`SOURCE_GAP`、`NOT_YET_LISTED`、`DELISTED`、`UNRESOLVED`。`UNRESOLVED` 均须报告；严禁全部填为停牌或当作当日未上涨。
5. 2005年原始涨跌幅存在非普通涨跌停幅度，股票等权收益需要公司行动/PIT复权及新股当日特殊规则；历史MA60、252日创新高低要按当日历史可见价格计算，禁止全历史终点前复权产生未来泄漏。
6. 两个供应商的上市/退市、停牌及关键价格交叉核验并保留冲突；质量门禁要求**事前可核实且无未处理严重缺口**，而不只是通过随机单元测试。

## 4. 研究数据等级

- `RAW_VERIFIED`: 收到并验证原始字节、日期、来源哈希，**不表示市场广度/PIT可靠**。
- `RESEARCH_ONLY`: 允许做受控诊断和敏感性分析；不进入正式双80成绩或生产。
- `PIT_CERTIFIED`: 所有历史上市/退市身份、停复牌、来源缺失和指标计算时点均有独立审计才准置true，当前均为false。
- `FORWARD_VALIDATED`: 模型预先冻结并在之后的真实新日期记录通知，等独立拐点客观确认后再一对一评价，当前为false。

## 5. 原始文件发布约束

Release内CSV是**外部供应商事后历史快照**，遵循来源方使用条件；不因为在GitHub可下载就视为官方或实时PIT。任何修改、清洗版必须另存，保留旧SHA256。上传的同名研究 CSV 可能因文本换行符标准化与本地 SHA256不同；**字节级判定优先使用Release源清单和原始ZIP**。
