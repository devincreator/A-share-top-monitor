# V97 第三道防未来函数：公告价格与归因所用价格必须一致

## 发现的潜在错误

V97已检查预测日D开盘前禁止使用D任何日级指标；也修复了把D−1收盘天然当作公布值的问题。但存在另一个独立风险：

- 一个历史报警的`INDEX_CLOSE`因子记录声明`observation_date=D−3`与`published_at`；
- 研究程序从后来下载的历史行情CSV提取D−3收盘价，用于计算60/120日市场阶段；
- 如果后来历史CSV发生订正、单位变化或当时官方披露值不同，则**观测日期和发布时间即使正确，也不代表当时可获得的数值和归因数值一致**。

为避免这种隐藏的回填效应，本轮使`preopen_event_audit.py`要求每条`INDEX_CLOSE`来源证据包含`observation_value`（该次预测时实际记录的指数收盘值），并与归档`prices.csv`在同一观测日的数值用`Decimal`精确比较。

缺少数值、零或非有限数值、与源归档不一致，一律`BLOCKED_FEATURE_CLOCK_OR_PROVENANCE`且不产出任何事件评分。没有`INDEX_CLOSE`而预测本来不要求指数价时，市场阶段只标`NO_INDEX_CLOSE_ASOF_SOURCE`而不虚构归因值。

## 仍未解决的限制

即使某条`observation_value`等于归档价，也仅说明**当时声称的价与研究档案相符**，不能独立证明`publication_evidence_uri`是有效历史原始披露时间，也不能证明该日之前全部60/120根行情在当时未被追溯修订。因此历史市场阶段的`lookback_vintage_PIT`明确设为false。

原始V63/V68`FORMAL_START`报警档案仍缺失，所有合成测试数据不计真实研究成绩。正式四任务双80与旧FP日期不生成。

## 回归覆盖

- 因子披露时点合法但未给出原始价 → BLOCKED；
- 原始价正确、事后档案发生变化 → BLOCKED；
- 更早但确实已发布的D−3价格与归档一致 → 研究时钟结构通过；
- 无指数价作为输入的事件 → 市场归因未知；
- 保留一对一最大匹配、左截断/PENDING和确认后140交易日缓冲。
