# V90｜融资异常隔离与按交易日窗口诊断（研究用途）

本模块避免两种错误：一是“某一条历史融资数据为零，因此所有近期研究都不能进行”；二是“跳过融资数据缺失日凑足窗口，就可以说长期因子完整”。

运行`isolate_window.py`时，使用V89归档的真实`000985`价格指数日序列作为对齐基准。**这只是候选交易日历，不是官方交易所日历认证**。融资余额仅采用上海与深圳分别可解析的原始**元**金额。零值、非数值、无穷值和数据缺报都保留异常原因，**绝不前填、插值、删除交易日再缩短时间间隔**。

研究验收按不同窗口独立进行：

| 研究因子 | 精确交易日需求 | 用途 |
|---|---:|---|
| 融资63日增长率 | 最近64个指数交易日 | 当日对比63个交易日前 |
| 融资近期252日完整性 | 最近253个指数交易日 | 近期基础数据检查 |
| 融资63日增长率相对于过去756期历史分位 | 最近820个指数交易日 | 当前增长率和此前756个增长率（不包含当前），每个增长率都需63期之前的融资数据 |

从V89于2026-10-21保存的历史`candidate_inputs.json`原始附件做初次逐日计数：最新63、252、253交易日均有对应融资日期；最近756期历史中有**182个缺失交易日、1个深圳融资原始零值（2024-08-08）**。这只是历史缺失范围诊断，不是自动通过上述全部窗口或证明融资信息在当时已经公布。V90云端审计会按820期精确输出完整的缺失数量及状态。

### 运行

```bash
python -m unittest discover -s research/v90_financing -p 'test_*.py' -v
python research/v90_financing/isolate_window.py \
  --input v89_source_audit_output/candidate_inputs.json \
  --asof 2026-10-20 \
  --output v89_source_audit_output/finance_windows.json
```

既有[独立数据源研究工作流](../../.github/workflows/v89-source-readiness-research.yml)在下载来源原始资料后运行这一审计，并在工作流附件中保留`finance_windows.json`。无论研究窗口状态如何，`formal_signal_allowed`恒为`false`，缺少交易所融资历史公告、具体可得时间戳、换手率独立来源以及正式模型完整还原时，**不能部署生产交易信号，也不能宣称双80验收成功**。
