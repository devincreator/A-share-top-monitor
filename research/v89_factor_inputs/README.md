# V89 指数和融资原始数据门禁（独立研究，不发正式信号）

## 目标

原有V88只认证来自单一第三方的**原始逐股成交观察日**，并不能填补中证全指价格指数、沪深300、中证1000、成交额、换手率及两市融资余额。V89新增一个独立研究执行链，**不调用生产模型、不更改生产文件**。

* 第一候选：中证指数公司网站`index-perf`接口。查询`000985 / 000300 / 000852`；只记录返回原始JSON、SHA256、字段结构及请求参数。即使得到HTTP 200，若未明确验证指数身份、字段单位和官方收盘口径，只标为`RAW_DOWNLOADED_NOT_YET_MAPPED`。
* 第二候选：AKShare `index_zh_a_hist`（经东方财富转接）三个指数的历史日线。逐日绑定请求指数代码，提供 `close/amount/turnover` 标准研究行；该绑定**不等于已由第二来源独立核实指数身份**。
* 第三候选：AKShare `macro_china_market_margin_sh/sz`（金十数据来源）按上海、深圳分别读取融资余额，明确单位为**元**，不把融资融券余额混成融资余额。
* 只采用先前V88真实获取、可校验的原始交易日作 `asof`，绝不默认最新自然日就有行情，也不要求融资当日一定公布。

## 判定与防未来函数

`strict_gate.py`要求：
1. 指数必须是`000985`、`000300`、`000852`，各至少756条有效日线，字段`date,close,amount,turnover`均存在，全部有明确代码、无重复日期、数值合法。
2. `000985`三个封存历史锚点（2026-08-04、09-30、10-08）必须符合旧生产价格指数量纲且误差不超过1点；不同指数不得混同。
3. 三指数必须具备所选`asof`的同日记录，不能有未来日期。
4. 两市融资各自余额须齐全，合并后至少850条日数据，所有记录单位元且指定日两市合计在历史合理数量级范围内（量纲启发式不是独立官方认证）。
5. 满足以上仅返回`PRIMITIVE_INPUTS_SCHEMA_VALID_RESEARCH_ONLY`，`formal_signal_allowed`永久为`false`。尚未证明历史发布时点、756日衍生因子窗口完整性、资金与官方指数独立同源校验或正式策略逻辑一致。

## 云端初次实测（2026-10-21，正式信号继续禁止）

GitHub Actions [39532734661](https://github.com/devincreator/A-share-top-monitor/actions/runs/39532734661)真实下载了2026-10-20以前的研究原始资料。原始文件存于GitHub Actions附件`12316555809`，保留期有限。

- 官方中证指数`index-perf`对`000985/000300/000852`均返回27条，其中`20260905`为星期六，必须**剔除到异常台账，不把该记录用作真实交易日**。
- AKShare/Eastmoney三条指数各1128条历史记录，均截至`2026-10-20`。官方与第三方共同覆盖的各26个**实际工作日**，每条指数收盘点位完全相同；官方`tradingValue`采用**亿元**，乘1亿元换算为元后，与AKShare`成交额`的四舍五入差异在研究容差以内。
- 当日三个指数收盘分别：中证全指`5306.57`、沪深300`4152.11`、中证1000`6766.90`。数值仅说明实测日来源数据，不意味着10月20日的正式模型已重新计算。
- 金十沪深两市融资原始记录各4015/3817条，日期交集3814条。**深圳融资余额2024-08-08为0**（该日期其他字段不等于真正零融资），仍缺独立来源对照，必须标为数据异常；首次完整融资门禁因此`BLOCKED`，不得用零值作融资增长率历史特征，更不得直接前值填补。
- 自动`cross_provider.py`只做逐日价格、成交额的跨提供者对照，并输出周末记录隔离和融资异常报告。中证指数公司与东方财富可能共享上游，不可把高度一致说成独立来源的历史PIT证明。

即使价格核对成功，融资的历史异值、换手率第二源、融资发布时点以及V86逐事件输入仍阻止四模块正式放行。

## 价格研究因子续算（严格研究层）

当且仅当`cross_provider_audit.json`证明`000985/000300/000852`的收盘与成交额逐日跨源吻合时，`price_only_research.py`计算`000985`的真实观测日价格因子：5/63日收益率、20/60日回撤、20/120日收益波动率比，以及相对于**前756个观测交易日（不含当日）**的历史百分位。它不使用未来数据、不修改现有正式仓位、不生成TOP/BOTTOM。

另作旧版公式差异对账：基于V89下载的1128条中证全指行情，2026-09-21的5日与63日收益率与旧`data/latest_state.json`吻合至四位小数；但V89严格排除当日的756日分位分别约为`14.6825/10.1852`，旧生产摘要为`14.8148/10.3175`，两项恰好相差一个756等分点。可能是历史分位计算窗口是否包含当日的定义不同，**未审计旧生产源码前不能强行宣布旧版计算错误或直接覆盖**。
