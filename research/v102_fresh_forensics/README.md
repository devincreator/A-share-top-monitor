# V102｜全新预警模型的独立误报审计与样本预热修正

V101 已从零生成59条历史模拟FORMAL_START，本阶段**不寻找旧版报警记录、不更改V101冻结阈值，也不把历史资料说成真实当年的预警**。使用中证全指000985.CSI在2022-02-23—2026-10-20的1128个已归档交易日，独立计算预警规则、事件匹配、误报和漏判，并固定原始文件SHA256。

## 本轮实质发现：5个被错误算成FN的「不可预测」拐点

现有价格模型在D日09:20使用的最新收盘价只能是D-1或更早；5%模块需要63个历史价格观察，9%模块需要126个。因此，5%模块的**首次可计算信号在价格观测序列索引63**，9%模块在索引126。若某个客观极值的完整1—10/1—20日提前预警窗口都发生在历史不足时，根本没有机会计算出任何信号，不应把它强行当作一次模型漏判。

首次V101评分没有排除这类*起始历史预热缺失*的可评价拐点（与原标签CSV的「左截断第一个拐点」是**两种不同问题**）。独立复算证实在原来的28个成熟FN中有**5个**没有足够历史来生成预测：

- 5%顶部：2022-03-23；1个
- 5%底部：2022-03-15、2022-04-26；2个
- 9%顶部：2022-06-28；1个
- 9%底部：2022-04-26；1个

条件更为保守：必须确保客观极值前**整个提前窗口**都在可以计算模型指标的交易日范围内，否则从Recall分母移除并单独报告，而不是修补缺失指标、加入未来数据或事后调参。被排除的这5条在V101原始评分中均未被TP命中，因此新的TP、FP数量不变。

| 任务 | V101原始TP/成熟拐点 | V102有完整信号计算机会的TP/拐点 | V101成熟FP |
|---|---:|---:|---:|
| 5% TOP | 8/16 = 50.0% | 8/15 = 53.3% | 11 |
| 5% BOTTOM | 6/16 = 37.5% | 6/14 = 42.9% | 12 |
| 9% TOP | 2/7 = 28.6% | 2/6 = 33.3% | 7 |
| 9% BOTTOM | 2/7 = 28.6% | 2/6 = 33.3% | 2 |

**精确率和模型预测能力均没有变化**。这是一份敏感性分析，用于修正评价样本资格；原V101研究基线及其TP/FP/FN永久保留，不回写。

## 误报和漏判的真实逐事件复算

本版本研究脚本`independent_audit.py`不导入V101代码，重新计算全部59条价格信号，再使用独立动态规划一对一配对，核对所有归档逐事件结果：

- 59条历史模拟预警日期、阈值观测值、对应信号与结果逐项一致。
- 原V101共有32条成熟误报、28个成熟漏判（包含上述5个未具备可计算窗口的客观标签）。
- 32个成熟FP中，有11个随后在**超过约定预警窗口、但没有超过其3倍距离**的交易日内出现了同向客观极值；另21个在3倍窗口内没有同向客观极值。这是**事后描述**，不能当成预测时已有的条件。
- 排除5个预热不足标签后剩余23个可评价漏判，其中21个在整个提前窗口内未同时满足位置/动量条件；另1个因冷却抑制新的正式启动，1个因为条件持续满足而没有新上穿边缘信号。
- 单独记录每个FP与FN的真实日期、来源、客观标签ID、已知D-1时点特征以及事后归因分类。所有归因属于研究分析，不是交易时可知的未来预测变量。
- 报告95% Wilson二项比例区间，提醒样本极少、市场事件并非统计独立，不能把区间当作真正样本外置信保证。

## 质量门禁

1. 价格、客观拐点、59条新报警和59条评分结果，四份源文件先核对不可修改的SHA256。
2. 决策日D及之后的收盘不进入当天报警；历史真实公布时点仍未独立认证。`D-1`已知只是**事后研究假设**。
3. 独立规则生成器和独立最大匹配DP逐行与冻结V101对照，不一致立即失败。
4. V101原始指标和V102样本资格敏感性分别展示，不通过调参得到更好的新模型。
5. 代码、原始输出和质量报告放在`research/v102_fresh_forensics`，与生产网页、生产策略、仓位隔离；研究可通过不代表四任务双80或历史PIT通过。
