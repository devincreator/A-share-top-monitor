# 量化学习路线图

路线分为 6 个阶段。你不需要一次性学完所有内容，每天只推进一个小块。

## 阶段 0：工具和基础习惯

目标：能顺畅使用 Python 做数据处理、画图、简单回测。

重点：
- Python 基础复盘：函数、类、异常、文件、虚拟环境。
- NumPy：数组、向量化、广播、随机数。
- pandas：时间序列、索引、缺失值、分组、滚动窗口。
- Matplotlib / Plotly：收益曲线、回撤、分布图。
- Git 基础：记录实验版本。

完成标准：
- 能读取价格数据。
- 能计算收益率、波动率、最大回撤、夏普比率。
- 能画出净值曲线和回撤曲线。

## 阶段 1：量化研究的统计基础

目标：理解策略背后的统计假设和常见陷阱。

重点：
- 收益率、对数收益、复利。
- 均值、方差、协方差、相关性。
- 抽样误差、置信区间、假设检验。
- 平稳性、自相关、异方差。
- 回归：OLS、残差、t 值、R 方、共线性。
- 多重检验和数据挖掘偏差。

完成标准：
- 能解释一个因子的 IC、t 值、换手率和衰减。
- 能判断一个回测结果是否可能过拟合。

## 阶段 2：经典策略框架

目标：掌握主流策略类型的逻辑、适用环境和风险来源。

重点：
- 趋势跟踪：动量、均线、突破。
- 均值回归：z-score、配对交易、统计套利。
- 因子投资：价值、质量、动量、低波、规模。
- 事件驱动：财报、调仓、公告、宏观数据。
- 期货 CTA：期限结构、展期收益、波动率目标。
- ETF / 多资产配置：风险平价、均值方差、Black-Litterman。

完成标准：
- 能说清一个策略赚的是什么钱。
- 能写出策略信号、持仓、交易成本、风险控制和评价指标。

## 阶段 3：回测和研究工程

目标：从“写个策略”升级到“可信的研究流程”。

重点：
- 数据清洗：复权、停牌、缺失值、异常值。
- 避免未来函数。
- 交易成本：佣金、滑点、冲击成本。
- 调仓逻辑：开盘、收盘、成交价假设。
- 样本内、样本外、滚动验证。
- 参数稳定性和敏感性分析。
- 日志、配置、实验记录。

完成标准：
- 能构建一个简单但不自欺的回测。
- 能写出策略研究报告。

## 阶段 4：机器学习和另类数据

目标：理解机器学习在量化中的正确位置，不把模型当魔法。

重点：
- 特征工程：滞后特征、滚动统计、标准化。
- 训练/验证/测试的时间序列切分。
- 线性模型、树模型、随机森林、XGBoost/LightGBM。
- 分类、回归、排序。
- 标签构造：未来收益、方向、分位数组合。
- 过拟合控制：正则化、交叉验证、特征筛选。
- 模型解释：特征重要性、稳定性。

完成标准：
- 能用机器学习做一个因子或择时实验。
- 能解释为什么模型结果可能不可交易。

## 阶段 5：组合、风控和实盘前检查

目标：把策略从研究结果变成可控的投资组合。

重点：
- 仓位管理：等权、波动率目标、风险预算。
- 组合优化：约束、换手、行业/风格暴露。
- 风险指标：VaR、ES、beta、跟踪误差、回撤。
- 压力测试和情景分析。
- 容量、流动性和交易冲击。
- 实盘监控：异常检测、信号漂移、回撤止损。

完成标准：
- 能设计策略上线前检查清单。
- 能判断一个策略是否值得继续投入。

## 建议节奏

- 每天 30 分钟：1 个概念 + 1 个小练习。
- 每天 60 分钟：概念 + 代码练习 + 复盘。
- 每周：完成一个小策略实验。
- 每月：写一份完整研究报告。
