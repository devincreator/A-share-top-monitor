# 量化学习模式

这个工作区用于长期跟踪你的量化学习。目标不是零散刷知识点，而是每天通过和 Codex 对话，稳定推进到能独立完成策略研究、回测、评估、迭代和实盘前风控检查。

## 你的起点

- 金融基础：CFA 二级，资产定价、组合、衍生品、财务分析有基础。
- 编程基础：知道基本语法，但需要把编程能力转成研究和工程能力。
- 推荐主线：Python + 统计学习 + 策略研究 + 回测框架 + 风险管理 + 交易执行。

## 每天怎么用

每天直接发：

```text
进入量化学习模式。今天我有 X 分钟。
昨天完成了：...
卡住的是：...
今天想学/练：...
```

如果你不知道学什么，就发：

```text
进入量化学习模式。今天我有 X 分钟，你来安排。
```

我会按 `daily_protocol.md` 工作：先复盘，再讲一个核心概念，然后给你一个小练习，最后记录进度和下一步。

## 文件说明

- `roadmap.md`：长期学习路线图。
- `daily_protocol.md`：每天和我对话时采用的固定流程。
- `progress_log.md`：学习进度记录。
- `knowledge_map.md`：量化知识地图。
- `exercise_bank.md`：练习题和项目题库。
- `references.md`：参考书索引和调用方式。
- `references/`：按主题分区存放的 PDF 参考资料。

## 学习原则

1. 先把每个概念落实到代码、数据或交易决策。
2. 不追求一次性学完，追求每天可验证的推进。
3. 每周至少完成一个小实验，而不是只看材料。
4. 策略评估必须同时看收益、风险、稳定性、交易成本和过拟合。
5. 所有结论默认需要数据验证。
