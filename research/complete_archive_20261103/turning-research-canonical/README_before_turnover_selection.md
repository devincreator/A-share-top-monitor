# 研究数据采用口径与换手率核验

按用户确认的规则，价格、成交额优先采用中证指数官方历史接口；融资采用重新获取的 iFinD 沪深融资余额序列。旧文件保持原样。

主表：tables/research_inputs.csv。范围 2011-08-02 至 2026-08-25，共 3659 个日期，包含五个已采用的数值字段。turnover_rate 列暂时留空，不代表零。

## 数据流

中证指数官方原始回执 → 检查代码、日期、重复值和正数 → 隔离休市异常记录 → 三条收盘价及中证全指成交额。

独立获取的沪深融资余额 → 保持原新序列 → 融资余额字段。

iFinD 换手率候选及分母样本 → 公式复算 → 暂不通过 → 候选表保留、主表留空。

## 官方序列与校验

来源：https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=000985&startDate=20110802&endDate=20260825

另两个代码为 000300、000852。完整请求、原始回执和时间见 raw/official。三条收盘价使用 close；成交额使用 000985 的 tradingValue，原单位亿元，乘 100000000 转为元。官方显示精度为 0.01 亿元，单位转换不意味着精确到元。

000985 和 000852 各返回一条 2018-06-18 记录：开高低为空、成交量和成交额为零。上交所公告确认当天休市，因此隔离这两行，保留原始回执。排除后，三条官方序列与独立重取表的 3659 个日期集合一致。这不等于已完成全时期交易日历认证。

休市依据：https://www.sse.com.cn/disclosure/announcement/general/c/c_20180606_4567900.shtml

上述结果只说明不能用这些已取得的字段直接复算，不证明 iFinD 换手率错误。分母字段回执使用“最新”参数，历史时点及成分范围尚未认证；也可能存在不同的成分范围或聚合方法。定义查询没有返回指标代码或计算公式；本机帮助文件中未检索到指数换手率说明。

放行条件：取得该指数换手率的确切指标代码及公式，确认分子、分母、成分范围、历史生效日期和异常值处理，然后跨年份抽样复算。仅找到通用个股换手率公式不足以放行。

## 使用限制

融资新序列作为研究主线，不宣称已认证历史发布时点。价格同样属于现在获取的官方历史值，不等于当时可见版本。

原模型会将 null 转成零，因此不要将本主表直接投入完整模型。换手率核验前，完整四模块信号和回测不具备放行条件。本次没有改写已有展示页面或历史回测结果。

## 文件索引

- tables/research_inputs.csv：主表，换手率留空。
- tables/turnover_rate_candidates.csv：独立重取换手率候选，全部标记隔离。
- tables/official_vs_ifind.csv：四项官方值与前一版供应商值的逐格差异，包含显示精度差异，不能将行数解释为错误数量。
- tables/quarantined_official_rows.csv：隔离的两条休市记录及依据。
- tables/field_lineage.csv、input_manifest.json：逐字段来源、输入哈希。
- source_policy.json、validation.json：采用规则和检查结果。
- build.py：从原始回执重建表格的脚本；融资原始来源仍引用相邻 turning-raw-reacquired 目录。
