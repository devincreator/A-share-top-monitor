# 完整数据需求清单

范围：现有中证全指5%/9%顶底研究及四模块因子扩展。当前冻结基线2022-02-23至2026-10-20；完整旧历史研究主区间2015年以来，2005年以来沪深300作为独立长期轨道，不能拼成中证全指。后续数据终点应选择统一已核验交易日。

| 数据组 | 原始字段 | 用途与要求 |
|---|---|---|
| 交易日历 | 市场、交易日期、开闭市、下一交易日、临时休市 | 对齐日频、T+1、提前天数和成熟窗口；不能只按周一到周五推算 |
| 指数日行情 | 000985/000300/000852的日期、收盘、成交额、换手率；开高低、成交量建议保留 | 价格收益、回撤、波动率、大小盘结构；收益率派生，不需重复采购。单位和换手率分母需明确 |
| 融资余额 | 日期、上交所融资余额、深交所融资余额、单位、精度 | 63日增长、过去756期分位。融资余额不是融资融券余额；北交所不得混入沪深基线 |
| 全市场逐股日行情 | 上市片段ID、代码、日期、原始OHLC、前收、成交额、成交量、交易状态 | C50、涨跌广度、MA60、252日新高新低；覆盖当时上市及后来退市证券 |
| 历史证券主表 | 上市片段ID、公司ID、代码、交易所、板块、证券类型、上市退市日、代码变更与主体继承关系 | 按当时真实上市证券构造股票池；保留北交所等用于明确排除或单列 |
| 停复牌与异常状态 | 证券ID、日期、停复牌、暂停上市、终止上市、生效日期、公告出处 | 区分真停牌、源漏采、尚未上市及身份错误。未解决状态不自动填零 |
| 公司行动与股本 | 除权除息日、分红送转、拆并股、配股、相关股本变动及公布时间；流通/自由流通股本视换手率定义而定 | 避免公司行动伪造涨跌、新高低；禁止使用含未来行动的全历史终点前复权 |
| 来源与历史可得性 | source_uri、抓取时间、观察日、实际公布时间、最早可用时间、版本、SHA256、修订记录 | 历史收盘已下载不等于当年盘前已知；各因子都需绑定来源和决策时钟 |
| 回测事件与执行记录 | 冻结规则/参数/代码版本、决策时间、特征快照、FORMAL_START、持仓变化、执行日价格、成本假设 | 客观5%/9%标签由价格派生；保留极值日、确认日、成熟状态、匹配结果。收益回测需指定实际交易载体，指数不是可直接成交资产 |

## 预热长度

- V101纯价格基线：最长126日价格位置、60日动量，需要在第一个评价日前准备足够历史；V103来源检查要求至少127个有效观测。
- 融资63日增长及前756期分位：820个交易日原始余额。
- C50：至少每日完整成交额横截面；20日变化与504/756期分位需要更早预热，具体叠加长度以最终实现核验，不能只取756天即称全部完成。
- MA60和252日新高低：每只证券的历史长度分别核查，新股不满足长度时另标状态。
- 标签评分：极值后需等待反转确认，并满足现有确认后140交易日成熟门禁；末端不成熟保持PENDING。

## 当前状态与边界

已本地核验：1128日指数收盘、58个标签、59条V101模拟事件；新取1128日沪深融资候选，64/253/820窗口完整，但历史时点和精确元金额尚未认证。其余分组尚未完成全区间验收。

现有代码已能从原始数据计算的收益率、动量、回撤、波动率、融资增长、C50、分位数和拐点，不作为新的原始数据采购项。新闻、财报、宏观、资金流向、Level-2和分钟行情不属于目前已确认的最低需求；新增模型假设后再决定。
