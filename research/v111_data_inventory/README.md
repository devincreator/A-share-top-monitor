# V111 数据获取实录与统一口径

本分支不是模拟行情：通过已验证过的 V89 AKShare/东方财富/金十抓取器，在 GitHub Actions 内重新请求三个指数（000985、000300、000852）和两市融资余额。保存取得的源响应和统一日期表，保留每项缺失、异常，不前值填充。

研究约定：指数价量 D-1、融资余额 D-2；已完整结束的周/月周期在下一周期首个交易日可用；公告使用**实际披露日期加1交易日**，不是财报所属期结束后直接出现。字段中的假设可用日是基于锚定交易日期序列计算的研究辅助字段，并非独立公布时点证明。

数据优先级：
- 现有 000985 历史收盘及 V89 的 000985/000300/000852 价量：历史观察，可重新获取
- V89 金十两市融资历史：有源数据但 2023–2025 多处缺口及 2024-08-08 深圳异常零值；V91/V92 交易所源为补缺候选
- 全市场个股广度和换手率：仓库 2005 年的 242 日研究数据，不等于 2022–2026 连续可用
- 公司财务与公告：必须按公司、公告和真实日期下载；目前不编造成交日起连续全市场财务表

工作流输出 `daily_unified.csv`、`data_coverage.json` 与所有原始响应。仅报告实测数量；若采集部分来源失败则数量下降并保持缺失，不宣布已完成。

不更改生产、双80质量门禁或原始冻结回测。
