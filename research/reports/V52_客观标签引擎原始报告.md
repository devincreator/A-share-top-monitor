## 标签引擎规则

对每个阈值独立执行状态机：

1. 初始化 `UNKNOWN`，不把资料第一天强制标为顶部或底部；缺失的起始段记 `LEFT_CENSORED`。
2. 上涨状态不断更新**截至当日**最高收盘价；后续收盘价从最高收盘价回撤至少5%或9%时，将那个最高点认定为 `TOP`，记录 **pivot_date（极值日）** 和 **confirmation_date（首次满足反转条件的日）**。
3. 下跌状态同理记录最低收盘价；后续上涨至少5%或9%时，认定 `BOTTOM`。
4. 如果新价格与历史极值完全相同，保留**较早**的极值日期；同一尺度客观顶底必须严格交替。
5. 最右端在未触发反转确认前只记录候选极值，波段标 `OPEN`，不补造对应端点。

确认滞后允许长于“预警提前窗”。极值标签产生于历史事实**完全发生之后**，仅用于事后监督标签与结构报告；绝不能在极值当天假定已经知道该顶/底存在。训练时只允许使用确认日**早于**预测日的标签。

## 一一对应审计

同一尺度内，连续两个已确认的反向端点形成一条唯一的完整波段（`market_legs.csv`）；一个底部、下一顶部、再下一个底部，形成一条完整循环（`market_cycles.csv`）。同一顶部同时作为上涨段的结束和下跌段的起始，是**一次事件的两个引用**，不重复生成顶部。

`pivot_lineage_one_to_one.csv` 为全部157个历史端点生成前一反向端点、后一反向端点的 ID 和时间，没有找到时留空，并标出右侧开放/左侧不完整。`market_legs.csv` 保留闭合状态、振幅和交易日长度。

两尺度独立从相同的收盘价历史标注。对每个9%端点，只允许找到一个同方向的5%历史主锚点；按**最大匹配数、最小交易日差**确定，主规则预先固定±5交易日，同时报告0/±3/±5交易日敏感性。本数据中全部 **51/51** 个9%端点均和5%同类端点**同日**匹配：0、3、5三种窗口得到相同结论，0个未映射。此结果是事后层级结构，不是9%顶部可提前预测的证据。

## 未来函数和历史一致性检查

V50 冻结的5%和9%极值与确认日期总计157条，V52重建 **157/157 完全一致**（逐个比较方向、尺度、极值日期、首次确认日期）。其他自动检查包括：

- 事件发生日严格早于首次确认日；回撤/反弹幅度达到正确尺度。
- 端点同尺度严格交替，波段与循环引用唯一，左右开放端点不造假。
- 提前截断原始序列或扰动未来价格，不改变截断日前的每日状态和已确认事件。
- 同一事件只有在 `confirmation_date` 当日收盘后才进入 `causal_market_state.csv`；训练端还必须要求确认日小于预测日。
- 重复日期、逆序数据、周末日期以及零价/无穷值在输入扫描时被拒绝。
- 完整数据重跑生成完全一致的 CSV SHA-256 哈希。
- 跨周期历史主锚点不可多对一；允许找不到，不通过修改极值日期强行配对。

**15项自动测试全部通过**。另外采用4% / 6%和8% / 10%规则检查标签数量敏感性，只作规则敏感性分析，不根据结果改变冻结的5%和9%阈值。

## 下一阶段与研究限制

本阶段不计算正式预警的 Precision、Recall、完整双端预警覆盖率，**没有达到或证明双80**。下一阶段需：①构建使用每日因果状态的5%候选顶部/底部预测头；②按真实标签可用日进行逐年训练；③以同一波段的一对一信号匹配评价；④再研究9%升级层。V50/V51已被多次查看的历史样本不能伪装成未知留出期。

其他限制：仅有三指数共同日期，不具备历史A股真实广度、成分股存续和股票池点时核验；来源为旧研究归档的中证指数行情CSV，尚未逐日独立比对交易所官方交易日历或历史指数数据修订；历史确认的时间戳不等于历史网页正式预警的发布日期。本阶段未修改 GitHub 项目和正式交易规则。
