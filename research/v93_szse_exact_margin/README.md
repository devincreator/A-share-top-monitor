# V93 深交所融资逐证券精确汇总的实际可行性检验

## 核心问题

V91/V92从深交所AKShare融资融券**市场汇总**能得到三段缺口里的候选融资余额，但该接口通常只保留两位小数的**亿元**；这不能直接还原精确元金额。2026-10-20市场汇总的显示换算值与金十原始余额相差796,294元，不能简单按±500,000元四舍五入解释。

V93尝试另一条数据链路：`ak.stock_margin_detail_szse(date=YYYYMMDD)`逐证券明细据AKShare文档以元列示融资余额。对完整列表逐证券求和，与同一天深交所公布的亿元市场汇总、金十原始余额作三方核对。

## 严格失败条件

- 原始证券代码、逐证券融资余额缺失；重复证券代码；出现非数值或负融资余额；证券数量明显不合理。
- 逐证券合计与市场汇总相差超过**100万元**，说明不能把明细误认为全部市场余额（可能存在已退出两融标的但仍有余额的证券等）。
- 即使合计和市场汇总在显示精度内一致，也不能自动宣称精确到元的市场融资余额准确，更不能证明当时该数据已发布或PIT。
- 对2026-10-20若逐证券总额与金十原始精确值一致，可获得更有力的**数学同口径**证据；若不一致，保留实际偏差，不人工填值。

## 抽查目标

`2024-08-08`（深市金十零值）、`2025-01-07`（深市历史缺日）、`2026-10-20`（有精确金十基准的最近交易日）。调用深交所只读接口，每日保留原始逐证券CSV、SHA256、证券数、合计与差值。正式模型、网页、质量门禁不因本探针自动改变。
