# 双80自主研究：长历史滚动实验

2026-11-10 的 P1 分数对齐在 [p1_score_alignment](p1_score_alignment/README.md)。它不替换本页的滚动实验，也不替换 `label_clock_v4` 的冻结基线。结论是 `BLOCKED_NO_CONCENTRATION`：close × price × past_rank90 的高分相对普通日有富集，但四项任务的峰值都在拐点后一天，有可评分日的漏报只有 21% 进过因果尾部。不开始发报压缩，不只提高阈值。同日的 P1b 特征时点审计在 [p1b_feature_timing](p1b_feature_timing/README.md)。它不重训。20日收益、距20日高点、距20日低点、63日区间位置在可命中窗口 −6..0 已经离开普通日，结论是 `GO_PRE_PIVOT_COORDINATE`，只放行以后预注册这些坐标；3日收益没有在两个任务上通过存在检验。P2 保持关闭，P1 的分数峰值仍在偏移 +1。未改生产，未认证 PIT，`formal_signal_allowed` 仍为 false。随后的 P1c 在 [p1c_slow_feature_score](p1c_slow_feature_score/README.md)。它不重训六特征模型，只用那四个慢变量的等权和，发报规则仍是 past_rank90。四项任务的平均分数和因果尾部都在偏移 +1，结论是 `BLOCKED_NO_WINDOW_PEAK`。精确率和覆盖率只与冻结基线对照，双80仍未达到。随后的 P1d 在 [p1d_fire_timing](p1d_fire_timing/README.md)。它不改发报规则，只把冻结六特征和四慢变量的真阳性、漏报、误报按预登记的时点分桶。四项任务上，漏报的多数都是窗口内从未进入因果尾部，结论是 `GO_NEW_FACTORS`。提前发报变体没有实现，P2 仍关闭。随后的 P4a 在 [p4a_factor_admission](p4a_factor_admission/README.md)。它不拟合。已有非价格家族都没有逐日披露时点，结论是 `NO_FAMILY_ADMITTED`。

目标未完成，生产模型未改。本轮使用2011-08-02至2026-08-25共3659日的现有研究输入，2016年起逐年比较。固定4个候选：价格基线、5日平均成交额低于20日平均的成交衰减过滤、5日小盘/大盘比率方向背离过滤、两者组合。顶部与底部方向事先固定，没有网格搜索。

每个任务每年只按此前成熟样本选择候选，优化训练期精确率与覆盖率的较小值，训练警报及目标各至少10个，否则回退基线。目标确认与140日缓冲必须已在训练截止日前完成。测试分数允许在后来评分，不能反向影响当时选择。

结论：5%顶部少4次误报且命中数不变，其他任务没有整体改善。不替换现有基线，不宣称双80。相比前期1128日短样本结果，本轮区间、源和评分边界不同，不能直接作为改进幅度比较；有效对照仅为同表两列。

训练选取没有用未来标签；48次前缀截断检验通过。但全部历史已被研究，这不是盲测，也不证明历史数据发布时点满足开盘前要求。未使用按今天存续个股构造的广度，指数历史成分范围仍未独立认证。

年度测试仅评分完整落在同一测试年内的7日机会窗口；训练和测试都保留边界排除，不能称为全部历史机会覆盖率。140日成熟门禁统一施加于归档末端，而非每年末端。初版逐年施加成熟缓冲丢弃过多机会，已保留初版诊断文件，最终采用修订评分。该修改属于评分实现修正，不能当模型进步。

继续方向：先扩大误报/漏判诊断，而非增加候选参数；核查触发频率、冷却期、目标定义与实际可预测特征的关系。新增信息必须逐项通过开盘前可用性检查，融资与换手率不自动放行。任何新候选累计登记；达成历史80%仍需未来冻结验证，不能承诺一定实现目标。

复算：python -B run.py。plan.json记录候选，result.json保存各年训练选取分数及测试分母，events.csv保存正式警报配对明细。本轮未认证PIT或生产放行。
