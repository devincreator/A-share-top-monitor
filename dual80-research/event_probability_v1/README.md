# 事件概率模型第一版：连续账本与成熟标签

本轮实际实现新路径，而非继续修改长期门槛。新模型不以长期位置和动量作为硬否决，每个交易日使用D-1及更早的6个连续价格特征，拟合固定L2约束的逻辑回归分数。

输入：波动标准化的3日、20日收益，3日收益速度变化，距过去20日高点和低点距离，63日区间位置。正则强度固定10，不搜索；阈值仅在此前年度验证段从预登记6个候选选择，没有使用测试年标签选择阈值。分数未经独立校准，不能解释为可靠概率值。

## 评分路径修复

训练只使用训练截止前确认且满足既定140日缓冲的拐点。负例的完整7日窗口不能越过当时最新成熟拐点的日期，因此未确定标签的尾部不会自动变成负例。相邻正样本按所属事件计权，不把一个拐点前7日视为7个独立事件。

年度选择后保留一个真实警报账本，冷却、重置不在跨年清空；模型切换也不凭空继承另一候选的影子警报。全局匹配允许跨年。最终评分只到同尺度已成熟的共同前沿，之后的警报明确PENDING。旧phase2脚本和成绩作为历史档案保留，没有覆盖；本版本提供新的同口径旧基线对照。

## 同机会集合的结果

|任务|原基线 精确率/覆盖率|事件模型 精确率/覆盖率|新模型待定警报|
|---|---|---|---:|
|5_TOP|30.6%/39.5%|25.0%/26.3%|5|
|5_BOTTOM|25.5%/30.8%|21.9%/53.8%|7|
|9_TOP|14.3%/16.7%|未定义（无可评分警报）/0.0%|0|
|9_BOTTOM|23.5%/21.1%|16.7%/21.1%|3|

结论：5%底命中从12/39提高到21/39，但误报从35提高到75，精确率反而下降，尚不具备采用条件。其他任务也未整体改善。9%顶部没有可评分警报，精确率未定义而非100%，不能判通过。

本表只在新共同成熟前沿内对照，不能直接拿以前逐年删边界的总成绩比较。5%共同前沿为2025-11-21，9%为2025-04-07；其后存在数据并不意味着标签均已满足保守140日成熟政策。

## 已执行验证

3次特征前缀一致性检查通过。额外将完整训练、验证阈值选择、年度重新拟合和连续发报流程分别截到1500行和2500行重跑，核对1220与4734条每日分数及阈值，以及25与89条已发警报日期，均与完整数据运行中对应前缀一致。未来数据仅改变后来的评分成熟状态，不得改变过去警报。

该检查不是历史发布时点认证。当前所有历史均已被研究，滚动测试不称为真正盲测；原始交易日历、发布时刻和指数历史成分范围仍未全面认证。生产模型未改，双80未完成。

## 对后续的约束

新结构确实能接触更多原门槛拒绝的底部，但目前没有足够区分力。不能只把阈值降低扩大覆盖，当作优化成功。后续只做预登记的小组增量信息对照：先成交额，再大小盘风格；所有变换限训练段拟合。开盘前可用时刻无法认证的融资和换手率不进入正式预警。9%少量事件不足以支持独立复杂模型，需明确样本数和不确定性。

运行依赖Python、NumPy，不新增安装；模型实现、先验计划、每日分数、全部正式警报与待定状态均保存在本目录。run.py执行主实验；plan.json是计划；result.json含逐年训练样本和阈值；events.csv、scores.csv是可追溯结果；full_pipeline_prefix_checks.json是完整流程前缀核查。
