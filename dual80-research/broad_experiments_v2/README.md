# 扩大实验：36组配置，全量保留结果

本轮分两批执行：先登记并跑6个特征组×2种发报机制，共12组逻辑回归；看到第一批结果后，再登记高斯分类、历史相似形态两类不同模型，共新增24组。合计36组配置，分别评估4任务，共144个任务配置结果，双80通过数为0。

这些属于同一批反复研究过的历史上的探索，并非36次独立盲测。不得在看过测试成绩后挑一个最好方案称为已验证策略。

## 实际测试范围

特征组：价格；价格+成交额；价格+大小盘风格；价格+成交额+风格；预先固定的价格交互项；价格+仅用当时价格确认的波段状态。后者的运行极值、阶段和确认时刻都在当时逐日更新，不读取未来事后标签作为特征。

模型：固定L2强度的逻辑回归；对角协方差并向全局方差收缩50%的高斯分类；训练段标准化后固定50个最近历史形态的加权投票。没有搜索正则强度、收缩系数或邻居数。

发报：分数上穿后发报、7日到期并回到阈值以下才重置；另一种要求回到阈值一半以下才重置。模型切换和跨年都保留真实已发警报状态，所有警报不可撤销。

所有模型每年只使用该年之前已经成熟的标签训练。阈值仅在过去三年、由当时模型产生的时间外分数上校准，再选择当前年使用的特征/发报配置。相对前一版扩大了验证期，并降低少事件任务的验证支持门槛至至少3个目标、5个警报，以便披露少样本下的选择行为；这仍是弱证据，不能称为可靠校准。三类模型各自独立进行过去信息选择，不按测试结果挑模型家族。

本批累计阈值验证比较14976次，属于内层研究搜索，不是14976个独立测试。所有失败和回退年份都在结果中保留。

## 两个值得理解但不能据此上线的事后观察

价格+风格、逻辑回归、较严格重置的5%底部方案：13次命中、26次误报、26次漏判，精确率和覆盖率均为33.3%。同口径原规则是12次命中、35次误报、27次漏判；改善幅度有限，且这一候选是查看全部测试结果后的描述性观察。不能将它追认为预先选定的赢家。

价格+风格、高斯分类、普通重置的9%底部方案：13次命中、62次误报、6次漏判，覆盖率68.4%，精确率17.3%。体现扩大捕捉范围的代价，不属于可采用方案。

逻辑回归家族只按过去验证信息选配置的9%底部，命中9/19、误报32，覆盖率47.4%、精确率22.0%；原规则命中4/19、误报13，覆盖率21.1%、精确率23.5%。这项增益同样没有同时解决误报问题。

## 时间稳定性

period_metrics.csv保留首批每组配置的2016—2018、2019—2021、2022—2026分段分母。上述5%底部33.3%/33.3%候选，在各段精确率分别33.3%、37.5%、31.3%，覆盖率36.4%、33.3%、31.3%；早段比原规则覆盖差，中段改善，末段覆盖相同。不能称为跨时期一致胜出。

分段精确率按警报年份，覆盖率按目标年份统计；跨年合法配对可能导致同一段的命中警报数与覆盖目标数不同，不能误当记账错误。

## 质量检查与适用限制

每类模型24项特征前缀检查。将完整流程截到2500行重跑，比较每日分数、年度阈值和配置选择、正式警报日期，不比较以后才可改变的成熟评分状态。逻辑回归已核对45984条分数、384条年度选择和1451条警报日期；高斯与近邻检查见additional_pipeline_prefix_audits.json。

首轮前缀测试发现旧规则对照未过滤前缀外索引，修正后完整样本成绩字节哈希不变。两条逻辑回归分数因批量浮点求和出现最大5.6e-17差异，数值检查采用1e-12容差，阈值选择和警报日期严格相同；没有据此放宽发报结果核查。

所有任务均执行TP/FP/PENDING数量守恒、同一目标不能重复命中等检查。完整流程前缀一致不等于历史发布时点认证。全局评分使用相同成熟前沿，初始评估边界只排除一次，不逐年删去跨年目标；5%前沿为2025-11-21，9%前沿为2025-04-07。

当前仍无历史发布时点、全时期交易日历及指数历史成分范围的全面独立认证。没有把今天存续个股回填历史，也没有声称已解决所有幸存者偏差。融资和换手率未自动进入模型，因其时点或分母范围仍待核验。

下一步不应仅因本批失败无限扩大同类参数搜索。保留少量有解释性的候选，针对哪些独立事件仍无法区分进行资料核查；如增加信息，先说明它对应的具体漏判/误报机制并确认当时可用。双80目标保持，不保证现有数据和模型一定能达到。
