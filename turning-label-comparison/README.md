# 收盘顶底与盘中极值比较：包含警报当天的7日窗

用户确认：开盘前D日发出警报，命中窗口为D到D+6，共7个交易日。原D+1到D+7只保留历史对照；这次不是在旧窗上额外加一天，所以D+7不再算命中。

本轮保持原有警报日期不变，没有重训模型。分别计算收盘标签和“盘中最高/最低价标极值、收盘反转确认”的标签，一对一评分。初始边界及末端成熟要求保持，两个定义使用共同成熟前沿，避免一边多看未来。

## 盘中版的定义边界

极值价格取日high/low；只有收盘相对运行极值完成5%/9%反向运动才确认。确认发生在收盘，新一段从这个收盘时点开始，不能把当天较早出现的low/high回填到确认之后。

这样不依赖同日high与low的先后顺序，但也不是纯粹的盘中达到幅度即确认。纯盘中版本必须知道日内路径，日线本身无法保证。

另用假设路径“开盘→最高→最低→收盘”和“开盘→最低→最高→收盘”作敏感性诊断：5%路径转折事件数分别248和290，9%分别91和95。这里包括假设路径内可能发生的同日多次转折，不能当作每日唯一真实顶底数，也不是两条路径涵盖所有可能情况。它们只是证明日内路径假设会影响标签，绝不据此选胜率较高的一条当真相。
